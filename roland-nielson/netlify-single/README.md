# Single-file build

`index.html` is the whole site packed into one self-contained file (hash routes like `/#/about/`),
generated by `node scripts/build-single.mjs netlify-single/index.html <commit-sha>` after `npm run build`.

It exists for one-file hosting (the Netlify connector's URL import). The normal Astro build in
`dist/` (real URLs, sitemaps, redirects, headers, form function) is still the production target.
